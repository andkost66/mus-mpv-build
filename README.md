mus-mpv-build

Build configuration for the mpv binary used by mus.

Current supported build:
- Linux x86_64.
- headless audio playback.
- PulseAudio and ALSA.
- WebM/Opus and M4A/AAC.
- HTTPS.
- JSON IPC.

The repository contains build configuration and regression fixtures.
Generated binaries are not stored in Git.
